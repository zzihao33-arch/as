# CM-HUB 本版本范围冻结（2026-09-18）

本文件记录用户于2026-09-18确认的版本范围。后续实施、验收和上线判断以此为准；旧计划中把Office在线预览作为本版本上线门槛的内容已被本决定覆盖。

## 本版本包含

1. 已上线的后台新版布局、工作概览、空提管理、推送日志、权限与响应式适配。
2. 空提列表组合筛选、跨页选择、批量目标完整读取、错误/空态、分页恢复及迟到响应保护。
3. 员工侧提货凭证基础能力：私有上传与授权读取、原件下载、PDF和图片在现有后台页面查看。Word/Excel原件可以保留和下载，但本版本不承诺在网页内转换成PDF预览。
4. 与上述能力直接相关的权限、审计、文件安全检查、测试环境联调和生产灰度开关。

## 下个版本处理

1. Office在线预览：DOC/DOCX/XLS/XLSX经LibreOffice转换为PDF、转换worker、租约/代次发布、版面保真、容量预算、强杀恢复及移动端预览链路。
2. 公共司机入口：司机专用登录或文件包会话、公开分享链路、司机侧移动页面及仅为该入口服务的文件分享能力。

后台交仓批次内已有的“司机姓名/电话/车牌”等内部录入字段属于仓库作业记录，不等同于公共司机入口，可以继续保留。

## 上线边界

- 当前发布树不得合入业务工作树中的017预览迁移、Office worker、LibreOffice容器或公共司机入口代码。
- 员工凭证基础能力在真实文件检查器、私有读取和权限回归通过前保持关闭。候选配置只有显式设置`PICKUP_DOCUMENTS_ENABLED=true`才启用；生产不得提前打开。
- Office预览的`G04=false`、B01版面保真HOLD、容量和worker恢复缺口不再阻塞本版本，但必须完整保留为下个版本的验收门槛，不能写成已通过或删除证据。
- 本版本不为了验收制造生产提单、上传生产测试文件或更改真实业务数据。

## 本版本剩余收尾

1. 从混合业务工作树中仅切出员工凭证基础能力，排除Office预览和司机入口。
2. 在测试环境验证真实文件检查、私有上传/下载、PDF/图片查看和权限拒绝。
3. 完成前后端回归、迁移边界检查和正式灰度；异常时保持功能开关关闭。

预计剩余1—2个工作日。若员工凭证基础能力也决定延期，则已上线的后台版本只需完成文档与最终健康复核即可收尾。
