# 仓库工作台采用全局上游数据可见性

所有有效仓库成员都可以处理所有上游客户推送的物流单据和 CM-HUB 面单资产，以支持同一业务网络内多个仓库和多台工作站并行换单。上游客户仍是 API Key、数据来源、幂等和结果回调的归属边界，但不再是仓库读取权限边界；仓库角色、账号状态、工作站归属和操作审计继续独立执行。

## Consequences

新增上游客户或仓库后无需维护交叉授权记录。任何仓库账号都属于受信任的内部操作域，因此未来如果需要为外包仓或独立法人隔离数据，必须引入新的组织或业务域边界，不能复用上游客户代码充当临时权限开关。
